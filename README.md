One word for make.fun's "One Word From Your Ex" bounty: the single word an ex would use to describe you — "Exhausting". It is the funniest, most painfully honest answer because it is both a complaint and a backhanded compliment, and it even starts with "ex". `main.py` writes the word to `/output/entry.txt`, deterministically, with no network and no randomness.

## Run it

```sh
python3 main.py
```

The word is written to `/output/entry.txt` (override with `OUTPUT_PATH`).
